# GitHub Info

## Mona's editorial angle

Mona's website focuses on practical GitHub guidance backed by official references from:

- docs.github.com
- github.blog
- github.blog/changelog
- awesome-copilot.github.com/workflows

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Repository-native, reviewable automation patterns from the Awesome Copilot workflows collection.
- Recent GitHub Blog and Changelog stories worth watching, including secure AI-assisted development and improved pull request review.

## Source guide

- **GitHub Blog** (`github.blog/latest/`): product strategy, engineering stories, and practical perspectives on how teams build with GitHub.
- **GitHub Changelog** (`github.blog/changelog/`): concise announcements for newly available GitHub features and improvements.
- **Awesome Copilot workflows** (`awesome-copilot.github.com/workflows/`): reusable agentic workflow examples that show how to automate repository tasks while keeping changes reviewable.
